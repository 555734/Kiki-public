# Trailer fonts

Used only by the trailer capture (tools/capture_trailer.gd); `tools/*` is
excluded from every export preset, so neither ships in the game.

- **Silkscreen** (Bold) — The Silkscreen Project Authors
- **Bebas Neue** (Regular) — Dharma Type

Both under the SIL Open Font License 1.1 (https://openfontlicense.org/),
fetched from github.com/google/fonts (ofl/silkscreen, ofl/bebasneue).
