# 1-6：砂時計の遺跡・20区間

実装前に20案を選定。前半10区間は既存の砂漠を発展させ、後半10区間は`desert_sections.gd`で個別に設計した。部屋テンプレートを繰り返さず、同じ仕掛けも地形・目的・組み合わせを変える。

| # | 区間 | 体験と組み合わせ |
|---|---|---|
| 1 | oasis_run | 安全な助走路から最初の段差へ。速度を整える |
| 2 | sand_columns | バネで独立した高い砂柱へ登り、次の地面へ降りる |
| 3 | low_thorn_corridor | 低い天井の下を歩く。短いジャンプと頭上の空間を読む |
| 4 | guarded_rope_bridge | 回廊の外の発射パッドから石橋の先へ。地上と空中の敵 |
| 5 | crumbling_hourglass | 3枚の崩れる床を止まらずに渡り、安全島へ |
| 6 | mirage_crossing | 射撃で蜃気楼の橋を出せる790pxの穴。ガーディアンの足場でも横断 |
| 7 | ruin_elevator | 縦の昇降機と中継棚。降りる高さを選ぶ |
| 8 | blink_fork | 3拍の点滅床を進む上道と、恒久棚の下道。コインは上道を示す |
| 9 | reversing_dunes | 逆転ベルトから下り段差へ跳び、速度を使う |
| 10 | sigil_causeway | 正しい紋章を射撃する門。二段ジャンプでも屋根を越せず、最後は崩れる床と隠し橋 |
| 11 | wind_well | 気流で砂柱へ浮かび、横に抜けて降りる。クラゲを射撃で除く |
| 12 | pendulum_tomb | 振り子の隙間と低い待機棚。サボテンと屋根のある退避先 |
| 13 | sun_wheel | 太陽の歯車のデッキに乗り、固定棚へ乗り換える。空中の見張り |
| 14 | piston_underpass | 歩いて地下道に降り、ピストンの安全な拍で進む。屋根の外のバネで脱出 |
| 15 | phase_transfer | 斜めに動く床から位相の違う点滅床へ。床ごとの周期を読む |
| 16 | warp_labyrinth | 低い入口から転送で上のバルコニーへ。別の高い棚に報酬を置く |
| 17 | sniper_windows | 二つの射撃窓から4秒の橋を維持。中央の島で再射撃する |
| 18 | rescue_wall | 430pxの高さは最大単独ジャンプでも届かない。足場2枚と狙撃による救援 |
| 19 | falling_escape | 下りの飛び石、崩れる床、発射パッド。追跡者から距離を取る |
| 20 | last_sandglass | 時計針の橋からベルトへ乗り換え、静かなゴールの眺望へ |

`Stage.data().rooms()`に区間名・入口・出口を、`Stage.route()`に40手の想定ルートを記録する。配置は通常のLevelBuilderが生成する。薄い追加棚は下から通過可能、厚い屋根・既存の岸は固体。チェックポイントは16か所の恒久地形上で、短時間の橋や崩れる床には置かない。

## 上下二層への改修

参考画像の二段の砂漠遺跡に合わせ、1〜10は下段、11〜20は同じ横幅内の上段に配置。上段の入口は(2200, -580)、下段の主な地面はy=20〜400。上段はx約2200〜10450へ重なり、従来の横一列の後半を別の位置に手作業で複写せず、既存SectionBuilderの入口座標から地形・仕掛け・敵・コイン・checkpoint・実ルートを一緒に生成する。

下段終端の印3の門から上段へ進み、上段のsniper_windows出口で鍵を取得。最後の印4の門から右下のゴールの岸へ戻る。鍵を下段に残さないため上段を飛ばしてゴールを開けない。追加の入口・出口も実ワープで踏破検査する。上下間に大きな砂時計、上段の棚の下に既存砂漠素材の支柱を描く。装飾には衝突を付けない。

全体マップは`build/desert-two-decks-map/stage-1-6.png`へ生成。開始・上段入口・上段終盤の3画面をVisual Regressionへ登録する。

`test/desert_route_probe.tscn`が各手順を実Runner・実ギミック・実Guardian足場で独立に検証する。横断では通常のダッシュ入力も使う。時間で動く床は複数のClock位相を試し、蜃気楼の橋は実スイッチを作動させる。敵と即死Areaはルート検査から外すため、敵込みの連続プレイ・全位相での成功・実機の難易度を保証する検査ではない。

区間名だけでなく、相対位置・足場寸法・移動方法を並べたルートの指紋でも20区間の重複を検査する。協力地点は`guardian_required_probe`で2速・2段ジャンプ・壁キックを試す有限探索と、足場で進める正例を併用する。描画と全体配置は`export_stage_maps.tscn -- --stage=1-6`で確認する。

二層の配置を持たないwire24の端末とは接続できないよう、協力通信をwire25へ更新。アプリは0.9.15/code42。今回ストア提出は行わない。
