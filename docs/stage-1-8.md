# 1-8 THE UNDERGROVE

横スクロールの地下ステージ。1-7の塔に続く協力ルートとして、静かな洞窟の背景と、読みやすい足場・敵・罠を組み合わせる。

## 経路と難度

- スタートからゴールまで約24,440px。前半でトロッコ、崩れる足場、上昇気流、バネ、落下鍾乳石、転がる岩を教える。
- 550〜560pxの大穴を3か所設けた。ランナーの単独ジャンプでは届かず、ガーディアンが足場を作って渡る。
- 後半の二つの大穴の先には記号扉がある。ランナーとガーディアンで記号を伝え合い、正しい遠隔スイッチを撃って開く。
- 後半は短い足場間のジャンプと、巡回する敵、動く罠、トゲを連続させる。鍵は最後の扉の先にある。
- チェックポイントは20か所。敵の地上巡回、岩の移動範囲、トゲから離した位置に置く。最後の難所からゴールまではチェックポイントを置かない。

## 敵と仕掛け

地上の穴掘り、スライム、キノコと、空中のコウモリ、甲虫の5種類。合計47体。トロッコ4台、落下鍾乳石と転がる岩を合わせて17個、崩れる足場15枚を配置した。位置と経路は `src/levels/level_cave_data.gd`、挙動は `src/entities/enemies/cave_enemy.gd` と `src/entities/gimmicks/cave_trap.gd` にある。

背景は `assets/stage_1_8/cave_back_wall.png`。当たり判定を持つ足場と罠はコードで描画し、背景から区別できるようにしている。選択カードは実画面を `test/cave_card_capture.tscn` で撮影した。

## 検証

`test/cave_stage_probe.tscn` は長さ、敵・仕掛けの数、3か所の協力用の大穴と足場設置、扉の開閉、鍵の位置、オンライン座標の範囲、チェックポイントの安全性を確認する。
