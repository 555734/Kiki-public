# リリース前の実機受け入れ確認

自動テスト（`tools/verify.sh --shots`、`tools/perf-gate.sh`、`tools/server-tests.sh`、
週次の `store-rehearsal.yml`）が通っていても、**PC 上では証明できないこと**が残ります。
オンライン・モバイル・課金の3つが交わるところが最大のリスクなので、ストアへ提出する
ビルドごとに、この表を上から順に実機で確認し、結果をリリースの PR かタグに貼ってください。

- 用意する端末：Android 実機 1 台以上（低めの性能のもの1台を含める）、iPhone 1 台以上
- 使うビルド：提出するのと**同じ**署名済みビルド（Play の内部テスト / TestFlight）
- 記録：各行に ✅ / ❌ / 該当なし、端末名、OS バージョン、気づいたこと

## A. オンライン（EOS）

| # | 確認すること | 合格の条件 |
|---|---|---|
| A1 | Android がホスト、Android がゲストで 1-1 を最後まで | 両方の画面で敵・足場・コインが一致し、クリアが両方に出る |
| A2 | Android ↔ iPhone（両方向でホストを入れ替えて） | A1 と同じ。部屋番号の入力から開始まで 30 秒以内 |
| A3 | プレイ中にゲスト側をホーム画面へ → 10 秒後に復帰 | 「つなぎ直しています」が出て、自動で復帰する。ランナーが巻き戻らない |
| A4 | Wi-Fi → モバイル回線に切り替え（ゲスト側） | A3 と同じ。90 秒以内に戻らなければ、分かる言葉で終了を告げる |
| A5 | ホスト側の画面を消灯 → 30 秒後に点灯 | ゲームが壊れず、部屋が続いているか、続かないことが表示される |
| A6 | 部屋を保ったまま次のステージへ（CoopRoom） | ホストだけが選べ、ゲストは待機表示、両方が同じステージで始まる |
| A7 | 2対2 / 1対1 / 最大人数の FFA を各 1 試合 | 全員が動け、スターの数が全員の画面で一致する。「やめる」で確認が出る |
| A8 | 異なるビルド同士（一つ前のストア版と新ビルド）で部屋を作る | 互換がなければ「バージョンが違います」と両者に表示される（黙って壊れない） |

## B. 課金

| # | 確認すること | 合格の条件 |
|---|---|---|
| B1 | Android（テスト用アカウント）で完全版を購入 | 1-3〜1-5 が開き、アプリ再起動後も開いたまま。1-6〜1-8 は購入前から遊べる |

## C. 端末の性能と操作感
