上下の交換は本当の転送先・進行ルートの交換であり、重力の向きそのものは変えない。射出ワープは任意の有限Vector2 `exit_velocity`を持ち、hostだけが転送とRunner.launchを同時に適用する。指定のない既存ワープは従来の速度を維持する。入口に射出方向の矢印、出口に対応する色と印を描く。落石には共有Clockによる予告表示がある。

## 検証と限界

- `radical_route_probe`は1-4の39手、1-5の41手を実Runner・実ギミック・実Guardian足場で検査する。部屋名と相対ルートの指紋で各20区間の重複も検査。チェックポイントは各11か所の恒久地形上。
- `guardian_required_probe`は各3地点に合法の2速・2段ジャンプ・壁キックを試す有限探索と、実Guardian足場での成功を併用する。単独突破が見つかった最後の溶岩横断は850pxに拡張した。
- `warp_launch_probe`はhost/guest、通常ワープ互換、クールダウン、無効な速度のschema拒否を検査する。
- 水・溶岩の実接触、アート参照、足場の支えは既存stage probeで検査。上下が重なる地形はX順の隣接距離では検証できないため、その近似を実ルート検査へ置き換えた。
- Visual Regressionは両ステージの開始・中盤・終盤を比較する。全体PNGは既存のstage-mapツールで通常の生成・描画から作る。
- ルート検査は敵と即死Areaを除く。敵込みの連続プレイ、全位相、実機の難易度、すべての操作列での単独突破不能を保証するものではない。

既存性能プローブで1-4は137 draws / 2815 objects、1-5は118 draws / 2830 objectsを計測。新しい内容に約10%の余裕を持たせ、1-4のdraw上限151、1-5のobject上限3115とした。他の上限は維持。

内容の不一致を安全に拒否するためco-opはwire24、アプリは0.9.14 / Android code41。今回ストアへの提出は行わない。
