# スタート画面 — ステージ選択と難易度

`src/ui/net_panel.gd` が2枚の画面を持つ。

1. **ステージを選択** — 5枚のカード（1-1〜1-5）だけ。
2. **遊び方を選択** — 選んだステージの大きな絵、**追跡者の速さ**、
   ローカル2人プレイ、オンラインの部屋作成／参加。

## 難易度はステージを選んだ後

`追跡者の速さ`（`Difficulty`）は2枚目に置いてある。
「このステージがどれくらい難しいか」という問いなので、
ステージが決まる前には答えようがない、というのが理由。

実装上もそこが最後の機会になっている。

- 追跡敵（`black_hole_chaser` / `sky_pursuer`）は毎フレーム
  `Difficulty.chase_scale()` を読むので、ステージを組み直す必要がない。
- オンラインではホストの値だけが効き、`EosCoopLobby` が部屋を作るときに
  `Difficulty.current()` を部屋の属性に載せる。ゲストはそれを採用する。
  部屋を作るボタンは2枚目にあるので、**部屋が立つ前に**必ず確定する。
- 値は `user://game.cfg` に保存され、次回も残る。

`HARD` がステージを調整した速さで、`NORMAL` / `EASY` は
すべての追跡敵を同じ係数（0.8 / 0.6）で遅くする。

## カードの絵

`assets/menu/card_1_1.png` 〜 `card_1_5.png`。
**ステージそのものを縦向きの窓で撮ったもの**で、
`tools/capture_stage_cards.gd` が書き出す。

```sh
xvfb-run -a godot --headless --path . --import
xvfb-run -a godot --path . tools/capture_stage_cards.tscn --fixed-fps 60
```

縦で撮るのはカードが幅の倍近く高いから。16:9 の画面写真を中央で切ると
空の柱になる。以前の絵はまさにそれで、1-1 は地面が1ピクセルも写っていない
背景画像そのもの、1-2 は板一枚のような SVG、1-5 は設定画の上3分の2だった。

撮影時は `NetPanel` / `Hud` / `PlacementPreview` / `Scope` を外す。
カードに写るのはステージであって、UI ではない。
カメラの位置と寄りはステージごとに `SHOTS` で持っている。

1-2 だけが今も彩度の低い見た目だが、これはステージの絵がそうであるため。
`assets/SOURCES.md` の「The reversal」にある通り、1-2 の描き込まれた素材5点は
意図的に SVG のプレースホルダへ戻してある。カードはステージ以上には
きれいにならない。

## カードの作り

絵の上に文字を置くために、下から上への**グラデーション**を敷く。
以前は不透明な帯を1本置いていて、絵の途中に硬い水平線が入り、
1枚のカードではなく2枚の画像が縦に並んで見えていた。
上側にも薄いグラデーションがあり、選択中を示す ✓ が明るい空の上でも読める。
