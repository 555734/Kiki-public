# ランナーの操作自由度を高める実装計画と変更内容

基準コード: `d08e5e5d59f6184a9fc41de1d818f5464a31c5b1`。
目標はDS版『New スーパーマリオブラザーズ』のように、入力と状況を組み合わせて
着地点やジャンプ高を選べる操作。任天堂のコード・素材・解析値は使用していない。
以下は走れメロス独自の調整開始値であり、マリオとの完全一致を検証した値ではない。

## 実装順序

1. 助走速度を踏み切り時に読み、ジャンプ高へ反映する。
2. 空中のブレーキ・反転・再加速を改善する。ダッシュボタンの意味を地上と空中で統一する。
3. 通常地形の壁キックと壁滑り、踏みつけの跳び分け、着地に合わせた3連続ジャンプを実装する。
4. スマホで2本指操作ができる自動ダッシュ設定を配置編集画面に出す。
5. 新しい操作の実行テストを追加し、旧仕様を要求する既存テストを更新する。
6. 協力ステージの評価を新しい移動能力に合わせる。操作を制限して協力を強制しない。

## 実装内容

| 操作 | ルール |
|---|---|
| 助走ジャンプ | 通常走行速度からダッシュ最高速度の間で、ジャンプ高を連続的に最大20%加算。停止中のダッシュ入力では増えない |
| 空中操作 | ダッシュを保持すると空中でもダッシュ速度が目標になる。逆入力でブレーキをかけ、反対方向へ再加速できる |
| 指を離す | 通常の空中移動は減速する。発射台で得たダッシュ上限以上の速度は緩やかに減速し、逆入力なら強くブレーキをかける |
| ダッシュ再入力 | ジャンプや落下の縦速度をゼロにしない。旧突進処理は通常入力から切り離し、既存の状態番号は維持する |
| 壁キック | 通常地形とガーディアンの壁で可能。壁への接触を検出し、外向きに0.08秒押し出す。回数上限は撤廃し、新しい接触で再び跳べる |
| 壁滑り | 空中で壁へ方向入力を続けると、落下速度を最大120px/秒に抑える |
| 踏みつけ | ジャンプ保持または先行入力があれば高く跳ねる。先行入力を消費し、以前のジャンプ解除による高さの切り詰めを引き継がない |
| 連続ジャンプ | 助走して着地から0.14秒以内に新しくジャンプ入力すると2段目、3段目へ。高さ倍率は1 / 1.18 / 1.38。4回目は1段目へ戻る |
| 連続状態の解除 | 方向反転、着地後の時間切れ、被弾、死亡、発射台、踏みつけ、崖つかまり、壁キック、リスポーンで解除する |
| スマホ設定 | ボタン配置画面のランナー／共有タブに自動ダッシュの切り替えを追加。既存の設定ファイルへ保存する |

通常走行速度は273.6px/秒、ダッシュ速度は410.4px/秒。
上昇重力・落下重力・短押しの仕組みは既存設定を基礎とする。
空中反転の減速係数は通常速度の2倍 / 0.20秒。
これは「ダッシュから完全な逆向き最高速度まで0.20秒」を保証する意味ではない。
空中反転と反転後の再加速は別の係数で処理する。

## 協力ステージ

1-Cの序盤と壁の区間は、壁キックや連続ジャンプを使った熟練者の別解を認める。
既存の支援ルートは残す。600pxの谷と、最後の480px幅・200px上昇の谷は、
発射台や足場の使いどころとして維持する。

`stage_probe` は支援ルートの成立を確認し、`movement_probe` は最高速度での
3連続ジャンプを実際に飛ばせて谷幅と比較する。
これらは全ルート・全操作列を探索するテストではなく、完全な単独攻略不能の証明ではない。
過去のジャンプ実測値を、新しい能力の限界値として使わないこと。

## 検証

追加した `test/movement_probe.tscn` は、実際のRunner、InputHub、静的地形を使用する。

- 助走の有無による高さ・距離、短押しと長押し。
- 上昇中・頂点付近・下降中からの反転。反転後の空中ダッシュ速度への再加速。
- 方向解除による減速と、空中ダッシュ再入力が縦速度を変えないこと。
- 2段目・3段目の高さ、4段目のリセット、時間切れと方向反転によるリセット。
- 押しっぱなしで着地後に自動ジャンプしないこと。
- 通常地形での壁滑りと4回の再接触キック。壁のない空中で跳べないこと。
- 踏みつけ時の入力による跳び分けと、古い入力状態の消去。
- 発射とリスポーンによる状態リセット。

既存の `tools/verify.sh` から追加テストを実行する。単体では:

```sh
godot --headless --editor --quit --path .
godot --headless --path . --fixed-fps 60 res://test/movement_probe.tscn
bash tools/verify.sh /path/to/godot
```

今回の作業環境ではGodotがなく、公式バイナリの取得も接続タイムアウトとなった。
GDScriptパーサーによる構文確認と差分の空白エラー確認は実施した。
Godotによる型解決・物理テスト・2プロセス通信試験・Android実機試験は未実施。
APKは更新していない。GitHub Actionsや外部CIは起動していない。

## 実機での仕上げ

同じブロック比率の平地と段差で、DS版の立ちジャンプ、助走ジャンプ、頂点での逆入力、
踏みつけ、壁キックを比較する。高さ・時間・着地点・入力遅延を別々に確認する。
さらにmoto g66j 5Gで、左右移動とジャンプを同時に操作し、自動ダッシュの有無を比較する。
ここまで確認してから「マリオと同等の手触り」と評価する。
