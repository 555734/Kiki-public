## 舞台の考え方

小鬼たちは劇場の出演者であり、装置を動かす舞台係でもある。幕、回り舞台、蛇腹、
照明、観覧車はそれぞれ働き方が違う。主人公は舞台を走り、相棒が射撃と描画で
演目の進行を変える。装置は敵にも主人公にも作用するので、動かした結果を見て
次の操作を決める。

見た目は動画から継承し、遊びの判断を変える。珊瑚色と青緑は世界の配色、
琥珀色の同心円は射撃できる機構、青い描線は相棒の足場として使う。
危険の予告は口の開閉、幕の揺れ、太鼓の振り上げ、橋の圧縮、照明の旋回で示す。
点灯だけに頼らず、形と動きでも読めるようにする。

## 舞台装置と二人の判断

| 区画 | 装置と変化 | 二人の操作 | 意外性と救済 |
| --- | --- | --- | --- |
| 01 FALSE ENTRANCE | 仮面門の下顎が橋になる | 主人公が噛みつきを避け、相棒が頬の留め金を撃つ | 開いた橋を敵も渡る。上に描いた足場へ退避できる |
| 02 BACKSTAGE | 幕と対重が反対方向に動き、上下の通路が切り替わる | 相棒が留め金を撃ち、主人公は対重に乗るか別の高さへ移る | 安全だった高さへ竹馬の敵が来る。落下時は下の受け足場で救う |
| 03 PARADE CROSSING | 回り舞台が群れを二つの出口へ振り分ける | 相棒がクラッチを撃って方向を切り替え、主人公が空いた出口へ進む | 鼓笛隊長の合図で群れが一斉に跳び、上ルートにも迫る。描いた足場で逃げる |
| 04 ACCORDION GAP | 敵の重みで橋が縮み、ばねのロックを外すと伸びる | 主人公が橋に乗り、相棒が圧縮量を見て解放・着地点を描く | 主人公と敵が一緒に跳ぶ。群れを貯める量と解放時刻で着地が変わる |
| 05 SPOTLIGHT GALLERY | 光を浴びた小道具が人形に変わり、暗所では固まって足場になる | 相棒が照明の向きを切り替え、主人公が暗くなった通路へ移る | 足場に使った小道具も再点灯で動く。二方向を予告して救出足場を確保する |
| 06 SKY WHEEL FINALE | 反対側のゴンドラへ敵が乗ると釣り合いが変わる | 主人公が乗り移り、相棒がブレーキを撃って停車・足場を描く | 敵の重さが移動の助けにも妨げにもなる。最後は本物の赤旗へ渡る |

回り舞台の資料にある大砲は演目用の補助装置。射線へ群れを誘導できるが、
主人公も同じ射線を通る。大砲だけの独立区画は増やさず、進路選択と結び付ける。
現在の巨大ハンマーを継続する場合も、この出口の危険として差し替えられる。

| 敵 | 形の特徴 | 装置や主人公との関係 |
| --- | --- | --- |
| WIND-UP GREMLIN / ぜんまい小鬼 | 丸い胴体、背中の鍵、赤い笑い仮面 | 既存デザイン。拡張案では群れの重さが橋・観覧車を動かす |

## 現在のゲームとの対応

現在の1−9には口の門2基、ハンマー2基、崩れる床3枚、昇降床2枚、小鬼72体がある。
現在の配置図は `src/levels/level_parade_data.gd` の座標を直接読む。図のシンボルは
機構の位置を示し、危険判定の形を表すものではない。

生成画4枚は拡張の設計案。新しい敵4種、下顎の橋、群れの重さ、幕の対重、回り舞台、
照明の変身、観覧車への乗り移りは今回のゲーム実装には追加していない。
拡張マップは空間構成のイメージであり、実測の当たり判定やジャンプ距離の図ではない。
既存能力との接続、操作の予告、チェックポイントと救済を設計段階で記載した。
面白さ、二人操作時の負荷、見落としやすさはプレイ可能な試作で確かめる必要がある。
