## 新しいプロットの中心

**普通のアクションだと思って見ていたら、約10秒で「あなたは相棒の道をつくり、撃って助ける側」だと分かる。その介入で、同じ失敗が成功へ変わる。**

参考動画の五つの驚きを、次のように移す。

1. 普通に進むと思った相棒が、追跡者につかまって死ぬ。
2. 寄った画面が引き、小さな段差だと思った場所の先に、大きな縦穴と連続する危険があると分かる。
3. 相棒を見ていた映像に、ガーディアンの操作画面が現れる。助ける側が「あなた」だと分かる。
4. 道として描いた足場が、撃つと相棒を飛ばす発射台になる。
5. 空中で受け止め、別の足場から再び射出する連携で、大きな空間を越えてゴールする。

大群と大量死の量的なインパクトは、現行の協力ゲームにそのまま移せない。Kiki側は「危険の規模」と「ふたりの操作で移動が大きく変わること」で強さを作る。最初の引きが単なる広い風景になると驚き2が弱くなるため、全景に相棒の小ささ、途切れた道、迫る追跡者を同時に入れる。冒頭の撮影区間は洞窟の縦穴を第一候補として、次工程の絵コンテと試し撮りで選ぶ。

## 絵コンテ・撮影に引き継ぐ判断基準

- 最初の10秒は、同じ危険区間を中心に、死→全景→再挑戦→役割の正体をつなぐ。別ステージを並べて導入の意味を途切れさせない。
- 「プレイヤーが誰か」を約10秒まで保留する。最初から1P・2Pの説明やタイトルを表示しない。
- 最初の介入は、一度失敗した場所を同じ構図で救う。視聴者が操作の効果を比較できるようにする。
- 24秒までに足場の描画、足場の印への射撃による射出、追跡者の停止、継続的な救援を見せる。後半で新しいルールの説明を始めない。
- 足場は同時2枚・各6秒。連続射出では使い終わった足場を入れ替える。多数の足場が残る一本道、ひとつの足場から繰り返し射出する映像は使わない。
- 足場の射出方向は相棒が向いた方向。照準を相棒の体へ向けず、実際の射出用の印に当てる。
- 画面の密度は実在する敵と仕掛け、切れ目、動く足場、操作の軌跡で作る。協力モードを大群の防衛ゲームに見せない。
- スローで尺を埋めない。予告、認識が変わる瞬間、成功する結果に尺を配分する。死亡直後や役割を明かす瞬間の短い間は残す。
- v2で使った単発救援の素材は一部再利用候補。ただし導入と最終リレーは、このプロットに合わせて撮り直す。
