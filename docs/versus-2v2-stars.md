# 2対2 スターたいせん

基準: `main` `e5416e4`（2026-09-27 時点の最新コミット）。

## 概要

| 項目 | 仕様 | 実装 |
|---|---|---|
| チーム | 2チーム × 2人。各チーム **ランナー1人＋ガーディアン1人**（最大4人） | `VersusRoster`（TEAM_SPLIT、席 0〜3） |
| 勝利 | **スターを先に 7 個「所持」したチーム**の勝ち | `VersusRules.WIN_AT = 7`、`VersusMatch._check_win` |
| スター | ホストの乱数でランダムな位置に出現。場には常に 2 個、総数 12 個 | `VersusRules.ON_FIELD / COIN_TOTAL`、`VersusMatch._free_point` |
| 奪い合い | 攻撃が当たると 1 個落とす。穴に落ちる・倒れると所持分をすべて場に戻す | `VersusMatch._drop_one / return_hand`（従来のコイン台帳 `ArenaCoin` をそのまま使用） |
| ステージ | **1-1 の素材**（草地スラブ・?/レンガブロック・土管・木・花・看板・柵・空）で作った左右対称の小型アリーナ。幅 3,200px、両端は高い壁、中央左右に小さな穴 | `VersusStageData`、`VersusLevelBuilder` |
| 相手位置 | 右上に**アリーナ全体のミニマップ**（地形・4人・場のスター）。画面外の相手ランナーとスターには**画面端の矢印と距離** | `versus_main.gd::map_marks / offscreen_marks`、`versus_hud.gd` |
| 通信 | **EOS**。協力プレイと同じ 6 桁番号＋P2P。4人ロビー（バケット `melos-versus`）、ホスト移譲なし | `EosVersusLobby`、`VersusEosTransport` |
| 料金 | **無料ユーザーもすべて遊べる**。部屋作成・参加・対戦のどこでも購入状態を見ない | `versus_probe.gd::_test_free_for_everyone` が検査 |

コード上はスターを従来どおり「coin」（台帳・通信形式・probe）と呼び、表示だけを「スター」にしています。

## 遊び方

1. ステージ選択画面の「⚔ 2対2 たいせん」を押す。
2. 部屋を作る人は「＋ 部屋を作る」。作った人は **Aチームのランナー**。画面の 6 桁を友達に伝える。
3. 参加する人は席（Bランナー／Aガーディアン／Bガーディアン）を選び、6 桁を入れて「入る」。
4. 待機画面に 4 席の状況が出る。**両チームのランナーがそろえばホストが「スタート」**を押せる（ガーディアン欠席でも開始可。欠席チームは建築なしのハンデ）。
5. 3・2・1 のカウントダウン中は全員スタート位置で停止。その後試合開始。
6. 決着後、ホストの「もういちど」で同じメンバーのまま再戦。誰でも「やめる」でメニューへ戻れる。

操作は従来の対戦と同じです。ランナーは移動スティック・ジャンプ・「攻撃」、ガーディアンは足場・壁・取消（狙撃とワープは対戦では無効）。

## 通信の流れ

- ホスト（Aランナーの端末）が試合を裁定し、スター台帳・命中・勝敗を決めます。各ランナーは自分の端末で即時に動き、位置をホストへ送ります（従来方式）。
- ホストは `VersusProtocol` v5 のスナップショットを 30Hz で配信します。v5 で追加したもの:
  - `epoch`: 再戦ごとに +1。クライアントは tick が 0 に戻っても新しい試合として受け入れ、自分のランナーをスタートへ戻す。
  - `countdown`: 開始までの残り tick。
  - `seat_mask`: 埋まっている席（待機画面の表示用）。
  - フェーズ `2 = 待機`、`3 = カウントダウン`（ホスト専用。ルールエンジンは入らない）。
- `VersusEosTransport` は EOSG のサーバー（peer 1）をゲーム上のホスト（peer 0）に対応させるスター型接続。参加者の切断はホストに BYE として届き、席が空きます。ホストの切断・退出は全員に「たいせんが 中断されました」と表示します（移譲はしません）。
- 開始したロビーは `started=1` になり、途中参加はできません。
- 旧 Cloudflare 中継（`VersusWsTransport`）はエディタ・コマンドライン起動（`tools/versus4.sh`）用に残しています。製品のメニューからは EOS のみです。

## 検証

`tools/verify.sh` で以下を実行します（Godot 4.7.2 headless）。

- `versus_probe`: アリーナの左右対称・両端の壁・全スター候補点の安全性・左右同数・ホーム前に出現しない・ブロックが一回のジャンプで届く高さ、乱数出現（同 seed で再現・seed で変化・4区画と複数の高さに分布・連続で同じ場所なし）、12 個の保存則、被弾で 1 個・死亡で全返却、7 個で勝利、ミニマップと画面外矢印の内容、購入チェックが対戦経路に無いこと。
- `versus_play_probe`: 実 Runner で立つ・歩く・拾う・攻撃で奪う・穴に落ちて全返却と自陣復帰・壁から出られない・ブロックの高さに届く・敵が存在しない。
- `versus_net_probe`: 4 端末の台帳一致（パケット損失・順序入替あり）、開始前は得点しない、カウントダウン、7 個で全員に決着、再戦を全員が一度だけ追従、古い試合のパケット拒否、EOS peer id の対応。
- `versus_team_probe`（新規）: 4 つの実シーン（ランナー2・ガーディアン2）で待機→スタート→カウントダウン→移動→建築が全員に反映→勝利→再戦→退出ボタン。
- `versus_touch_probe`: 実タッチでの操作（1対1 の既存経路）。

**未検証（実機で確認が必要）:** EOS SDK はこのリポジトリに含まれず CI でのみ導入されるため、EOS ロビー作成・検索・4人 P2P 接続は headless では実行していません。リリース前に、異なる回線の実機 4 台で以下を確認してください。

1. 部屋作成と 3 人の参加（席の重複は拒否される）。
2. 無料版の端末だけで部屋作成・参加・試合・再戦ができる。
3. スタート→カウントダウン→試合→7 個で決着→「もういちど」。
4. 参加者 1 人のアプリ終了で席が空き、試合は続く。
5. ホストのアプリ終了で全員に中断表示が出て「やめる」で戻れる。
6. EOS リレー経由（直接接続できない回線）でも成立する。
