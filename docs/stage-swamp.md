# Stage 1-5 — THE POISON MARSH

ステージ5は、明るい空の下に広がる毒沼を左から右へ渡る協力ステージ。
緑の水面は接触で即死し、苔の岸・石・木橋・筏が安全な足場になる。
画面の色と素材感は `assets/stage_1_5/concept_board_v3.png` を基準にした。

## 経路

1. 最初の岸で操作を整え、小石を連続ジャンプする。
2. 壊れた橋の先はガーディアンが足場を置いて渡す。
3. 石柱を越えて、2本目の広い水路を足場で渡す。
4. 動く丸太筏に乗り、中央の長い毒沼を渡る。
5. 最後の水路を足場で渡り、奥の門に到着する。

## 難易度

自由ジャンプの隙間は 152〜190px。歩きジャンプの到達距離は約 182px なので、
広い側の隙間は走り出してからでないと届かない。石の幅は 94〜112px まで
削り、高さを ±24px ずらしたので、着地点は走者の体幅に近く踏み直しも効かない。
木橋も 220px から 170px に詰めた。

ガーディアンが必要な隙間は 630〜730px で3箇所。その内側に崩落床を
計4枚置いた（x=2836 / 3086 / 5980 / 8810）。崩落床は 0.45 秒しか床では
ないので、どの水路も「足場1枚を置いて終わり」ではなく、崩落床を挟んだ
2手の段取りになる。

丸太筏は甲板を 180px から 130px に狭め、移動距離を 800px に伸ばした。
乗り込みと降りるタイミングの両方が跳び移りになる。

飛行敵は跳躍の弧の上ではなく弧の中に配置した（x=1300 を y=340 に下げ、
x=4560 と x=7250 を追加）。石渡りと筏の区間はまずガーディアンの射撃が要る。
歩行敵の巡回幅も 110〜150px から 170〜210px に広げ、岸の上で待つ余地を狭めた。

チェックポイントは6箇所のまま。協力ステージで長いやり直しを課すのは
難しさの方向として正しくないので、1回の失敗が重くならないようにしている。
毒の判定は水面に沿った透明な `Hazard` で、落下判定より先に死亡する。
