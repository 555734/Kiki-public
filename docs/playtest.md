# 遠隔でテストプレイする（Android ↔ iOS）

**クロスプレイできます。** 両方 Godot の同じコードなので、Android と iOS の
組み合わせで問題ありません。中継サーバー経由なので、離れていて構いません。

---

## 準備

| | 誰 | 何を |
|---|---|---|
| 1 | あなた（Android） | `dist/side-sky-gles3.apk` を端末に入れる |
| 2 | お友達（iOS） | TestFlight の招待を受けて入れる |
| 3 | 両方 | **同じバージョンであること**（下記） |

### バージョンを揃える

**両方が同じコミットのビルドである必要があります。** 違うと、繋いだ瞬間に
ガーディアン側へ

```
バージョンが違います（相手 N / こちら M）。同じビルドを使ってください
```

と表示されます（黙って壊れないようにしてあります）。

APK を更新したら iOS も、iOS を更新したら APK も入れ直してください。

---

## つなぎ方

> **遊び方は2つだけです。** 1台を2人で持つか、合言葉で部屋に入るか。
> 合言葉のほうは、同じ部屋にいても離れていても同じ手順で動きます。
>
> **つながらないときにアプリを終了する必要はありません。** 中継につながらな
> かった場合は数秒おきに自動で掛け直しますし、最初の画面に戻って
> 「部屋を作る」「合言葉で入る」を押し直せば、前の接続は必ず破棄されます。
> （以前はここが残ったままで、本当に再起動しないと入れませんでした）

**どちらがランナーをやるか決めます。** ランナー側の端末がシミュレーションを持つので、
**操作が重くなるのはガーディアン側だけ**です（設計上そうしてあります）。

### ランナー役の人

1. アプリを起動
2. 一番下の **「インターネット（離れていても）」** の
   **「部屋を作る（あなたがランナー）」** を押す
3. **6文字の合言葉**が出るので、相手に伝える（LINE でも電話でも）

### ガーディアン役の人

1. アプリを起動
2. 同じ欄の **合言葉** に6文字を入れる
3. **「合言葉で入る（あなたがガーディアン）」** を押す

繋がると接続画面が消えて、ゲームが始まります。

**中継サーバーのURLは入力済み**です。触らないでください。

## 操作

| | |
|---|---|
| **ランナー**（画面全部を使えます） | 左下に**丸いスティック**、右下に **JUMP** と **SPRINT** の丸ボタン（親指2本で持つ形）。スティックを**上に弾いてもジャンプ**できます（走りが途切れません） |
| **ガーディアン**（画面全部を使えます） | 右側の**丸ボタンの弧**（下から ワープ／足場／壁／狙撃／スコープ）を**押したまま指を動かして、離す**。離した所に出ます。画面のどこをドラッグしても照準は動きます |

**端末ごとに、自分の役の操作しか出ません。**
ランナーの画面にはガーディアンの能力バーもスコープも出ませんし、
ガーディアンの画面にはスティックが出ません。
ランナーの画面に点線の四角が浮かんだら、それは**相手が今そこに足場を置こうとしている**合図です
（相手が照準を動かして初めて出ます）。

> 1台に2人で座って遊ぶときだけは、左3割がランナー・右がガーディアンで、
> JUMP と SPRINT はスティックの隣に残ります。右下はガーディアンの弧だからです。

ガーディアンの足場には**ゲージ**があり、無限には置けません。
これが「神側が強すぎてランナーが駒になる」のを防ぐ唯一の制約です。

### ボタンの位置と大きさは自由に変えられます

最初の画面の **「ボタンの位置を変える」** から。

- 上のタブで **ガーディアン／ランナー／1台で2人** を選びます（3つは別の配置です）
- 動かしたいボタンを**指でドラッグ**するだけ。離した所が新しい位置です
- 触ったボタンが選ばれるので、上の **「大きさ」スライダー**でそのボタンのサイズを変えられます（0.6〜1.8倍）
- **「保存して閉じる」**で保存。アプリを閉じても残ります
- 気に入らなければ**「この配置をリセット」**で元に戻ります

> ボタンは全部**丸**で、**左右の親指に分けて**置いてあります。
> 手の大きさも端末も持ち方も人それぞれなので、はじめの配置はあくまで初期値です。

### 視点は「画面を横に払う」だけ

**ボタンはやめました。** 何もない所を**指で横に払う**と、地図と同じように視界が動きます。
26px以上横に動かすとスクロール、それ未満は照準の微調整です。

**動かした視点は、指を離してもそのまま残ります。** 戻すときは逆に払ってください。

- **ランナーが画面から消えることはありません。** 動かせる範囲は
  「画面半分マイナス150px」で自動的に頭打ちになります
- やられて再開したときは、視点も**ランナーに戻ります**
- 視点を動かしても、**足場を置ける範囲はランナーからの距離で決まったまま**です

### 道具は「選ぶ → 置きたい所をタップ」

**ルールは1つだけです。**

1. **道具のボタンを押す** → その道具が**選ばれます**（何も出ませんし、ゲージも減りません）
2. **置きたい場所をタップ** → そこに出ます

**選んだ道具はそのまま**なので、続けて置くときは**画面をタップするだけ**です。

急ぐときは **ボタンから指を引き出して、置きたい所で離す**でも構いません（1回の操作で1つ）。
途中でやめたくなったら、**ボタンの上まで指を戻して離す**とキャンセルされます
（何も出ませんし、ゲージも減りません）。

**ゴーストが出ている所が、必ず出る所**です。指より上にずらす補正は**なくしました**。
置けない場所をタップしたときは、勝手に別の場所へ動かさず、**理由が出ます**。

> **以前は違いました。** ボタンをポンと押すと、ゲームが「必要な所」を
> 勝手に決めて置いていました（落ちているランナーの真下、敵との間、など）。
> 狙う手間を無くすつもりでしたが、これは
> **プレイヤーが既に指した場所を黙って書き換える**動きで、
> 「壁ボタンを押しても全然違う所に壁ができる」の正体でした。
> ルールが少しズレているという話ではなく、
> **コントロールが信用できない**という話なので、自動配置は丸ごと消しました。
> FIREも同じ扱いです（照準の所に撃ちます）。

### 足場をタップすると、そこに乗っているランナーが打ち上がる

ガーディアンの新しい動詞です。**置く**のではなく、**すでに置いてあるものに働きかける**もの。

- ランナーが**あなたの置いた足場の上に乗っている**状態で、
- その**足場をタップ**すると、ランナーが**真上に打ち上がります**

高さは**自力ジャンプの約2倍**（約256px）。ボタンもゲージも要りません。
乗っていない足場をタップしても何も起きないので、
「どこからでも発射できるボタン」にはなりません。

調整値は `Balance.PLATFORM_LAUNCH_VELOCITY` の1つだけです。

### 狙撃は「照準を合わせて、FIREを押す」だけ

- **照準は常に出ています**（最初はランナーの上に乗っています）
- **空いている所をドラッグ**すれば照準が動きます
- 赤くて大きい **FIRE** ボタンを**押すだけ**で、その照準の所に撃ちます

**ぴったり合わせる必要はありません。** 近くに敵がいれば自動で狙います
（照準から110pxまで）。狙える敵がいるときは、その敵に**赤い四隅のマーク**が出ます。
マークが出ていれば当たります。

> **以前は当たりませんでした。** 道具をボタンから引き出すとき、
> 指の下に隠れないよう**照準を指より少し上**にずらしていたのですが、
> それが狙撃にも効いていて、弾は**敵の頭上74px**を通っていました。
> 敵の身長は42pxなので、毎回きれいに外していたことになります。
> 狙撃だけ、このずらしを無くしました。

### 道具は「押したまま引き出して、離す」

**モードはありません。** 道具を「選ぶ」操作はなくなりました。
ボタンを**押している間がその道具**で、**指を離した所が確定**です。

1. 出したい道具のボタンに指を置く（この時点ではまだ何も出ません）
2. 指を置きたい場所まで動かす（**ゴーストが指についてきます**）
3. 離す → そこに出ます

- 狙撃（3番）も同じです。押したまま狙って、**離した所に撃ちます**
- ドラッグせずに**そのまま離せば**、画面に出ている照準の所に出ます
  （つまり「タップして狙う → ボタンを押す」も、そのまま使えます）
- ゴーストは**指より少し上**に出ます。指の下だと足場が隠れて、
  「ランナーの足元か頭の上か」が見えないためです

> **なぜこうしたか。** 能力バーは画面の下にあり、地面も画面の下にあります。
> 「地面をタップして狙う → ボタンを押す」だと、狙うための指がバーに当たって
> しまい、**道具が古い照準の場所に出てしまう**——
> 「置きたい所に置けない」「確定できない」の正体はこれでした。
> ボタンから引き出す形なら、バーのある所を触る必要がそもそもありません。

**照準は「画面の座標」ではなく「世界の座標」になりました。**
以前はカメラが動くと照準が地面の上を滑っていったので、
狙ってからボタンに手を伸ばす間に**目標が最大120pxずれて**いました。
今は一度合わせたら、ランナーが走っても同じ地面を指したままです。

右端の丸ボタンは**スコープの入/切**専用です。
スコープは拡大鏡であって道具ではないので、**構えたままでも足場や壁は置けます**。

### ワープ（4番）

**2回引き出して1組**です。1回目で入口、2回目で出口。
ランナーがどちらかに入ると、もう片方から出ます。

- 1つにつき **22**、1組で **44**。足場と壁を両方置くより高い
- 1つずつ**9秒**で消えます。しかも時計は置いた瞬間から動くので、
  2つ目をもたつくとその分だけ組んで使える時間が減ります
- リンクしていない片割れは**オレンジ色**で描かれます。青くなったら通れます
- 他の能力と同じで、ランナーから離れすぎた場所には置けません

落下が確定したとき、閉まる扉の向こうに取り残されたとき、
足場を置いても届かないときのための道具です。

### 被弾2回でゲームオーバー

ランナーの体力は**2**です。2回当たると **GAME OVER** が出て、
直前のチェックポイントからやり直しになります（約1.5秒）。

1回目の被弾のあとは**約1.2秒の無敵時間**があるので、
砲台の連射をまとめて食らって即死することはありません。
穴に落ちるのは従来どおり即死です。

> ステージ丸ごとやり直しではなく**チェックポイントから**にしてあります。
> 遠隔の2人プレイで穴に落ちるたびに最初からだと、まず続かないので。
> 丸ごとやり直しにしたい場合は言ってください（1行です）。

### コインとバネ

ステージの本筋から少し外れた所に**バネ**があり、その上に**コイン**が並んでいます。
コインはランナーが取ると**ガーディアンのゲージが回復**します。
ランナーからガーディアンに返せるものは、これだけです。

### 間に合わせた「うまさ」が点になる（NICE / GREAT / PERFECT）

落下中のランナーの下に足場を差し込んで受け止めると、
**置いてから踏まれるまでの時間**で評価が出て、ゲージが戻ってきます。

| 評価 | 置いてから踏まれるまで | ゲージ還元 |
|---|---|---|
| **PERFECT!** | 0.35 秒以内 | +24 |
| **GREAT!** | 0.8 秒以内 | +14 |
| **NICE!** | 1.6 秒以内 | +6 |

- 落下速度が **420px/秒未満**だと「受け止めた」とは見なしません。
  置きっぱなしの足場にランナーがひょいと乗っても点にはなりません
- 評価はステージクリア画面に **BEST CATCH** として残ります
- **回線が悪いほうが不利にならないようにしてあります。**
  ホストは遅延補償で足場の「誕生時刻」を過去にずらしますが、
  評価はずらす前の**実際にボタンを押した時刻**で採点します

> ぎりぎりで受け止めるほどゲージが戻るので、
> 「安全に早めに置く」より「引きつけて置く」ほうが次の手が打てます。
> ガーディアンが置きに徹するだけの係にならないための仕掛けです。

### 音が入りました

BGM と効果音を29種類入れてあります。ジャンプ、着地、ダッシュ、被弾、
足場・壁・ワープの設置、狙撃、敵の撃破、コイン、バネ、スイッチ、
チェックポイント、評価音、クリア、ゲームオーバー。

- **ランナーが危ないとき、BGM に層が増えます。** 残り体力1のとき、または
  落下速度が上がったときだけ、上に乗るパートが入ります。曲は切り替わりません
  （同じ位置・同じキーのまま重なるだけです）
- ガーディアン側の端末でも**同じ音が鳴ります**。ホストから届いた出来事と、
  受け取った位置情報から着地・ジャンプを復元して鳴らしているので、
  ガーディアンの端末が何もシミュレートしていなくても音は揃います

> 音は**合成音**です（波形をスクリプトで生成しています）。
> 録音素材や作曲データをいただければ差し替えられる作りにしてあります。

### 通信が切れても戻れます

ガーディアン側の通信が切れたとき、これまではセッションが終わりでしたが、
今は**自動でつなぎ直します**。

- 4秒間なにも届かなければ「切れた」と判断し、画面上部に
  **「つなぎ直しています…」**の帯が出ます
- 2秒おきに、同じ合言葉の部屋へ入り直します。**最大90秒**まで試します
- つながると、ホストが**その間に起きたこと**を送り直します
  （生きている足場・壁・ワープ、開いたスイッチ）。
  部屋に入り直したのに世界が空っぽ、ということにはなりません
- 90秒であきらめたときは、その旨が帯に出ます。部屋に入り直してください

> アプリを裏に回した、Wi-Fi↔LTE が切り替わった、電波が一瞬切れた——
> モバイルでは普通に起きることなので、ここは落ちない側に倒しています。

## うまくいかないとき

### まず「接続診断」を押してください

最初の画面の下に **「つながらないときは → 接続診断」** があります。
押すと、この端末から接続の全工程を実際に試して、記録を出します。

1. 中継サーバーに HTTP で届くか
2. 部屋を作れるか
3. **WebSocket がつながるか**（HTTPは通るのにここで止まる回線があります）

**「すべてコピー」でクリップボードに入る**ので、そのまま送ってください。
どこで止まったかが分かれば原因はほぼ確定します。

| 症状 | 原因 |
|---|---|
| 「バージョンが違います」 | 片方が古いビルド。両方入れ直す |
| 合言葉を入れても繋がらない | 合言葉の打ち間違い（`0`と`O`、`1`と`I`は**使っていません**）。または相手がまだ「部屋を作る」を押していない |
| ずっと「接続しています…」 | 中継サーバーに届いていない。両方の端末がインターネットに出られるか確認 |
| ガーディアンの操作が少し遅れる | **仕様です。** ランナーの操作を優先する設計で、遅延はガーディアン側に寄せてあります。ただし遅れは**往復時間の半分＋50ms 程度**で、0.5秒も遅れるなら不具合です（実測 16〜33ms） |
| 足場が間に合わなかった | 遅延補償は 250ms までです。それ以上遅れると、単に間に合いません |
| 診断の [1/4] で失敗する | この端末がインターネットに出られていません。機内モード／VPN／フィルタ |
| 診断の [1/4] は通るのに [3/4] で止まる | そのWi-FiがWebSocketを遮断しています（社内・学校・ホテルに多い）。携帯回線のテザリングで試してください |
| 診断は全部通るのに繋がらない | 二人の合言葉かURLが違います。または片方が「部屋を作る」を押していません |
| 「バージョンが違います」と出る | 片方が古いビルドです。両方入れ直してください |
| 一瞬「つなぎ直しています」と出る | 無音が**7秒**続くと出ます（4秒から延ばしました）。モバイルでは数秒の停滞は普通に起きるので、出てもそのまま遊べることが多いです |
| 一度つながったのに切れて戻らない | 90秒試して駄目なら接続画面に戻ります。そこで「接続診断」を押すと、**いま動いている通信の数字**（受信数・往復・無音の長さ）も出ます |

## 分かっている限界

- **ホスト移譲がありません。** ランナー側が落ちるとセッションは終わりです。
  つなぎ直しが効くのはガーディアン側だけです
- **つなぎ直しは90秒まで。** それを超えたら部屋に入り直してください
- **音は合成音です。** 録音・作曲したものではありません
- 中継は TCP なので、パケットが1つ落ちると後ろが少しつかえます
