# Stage 1-6 — THE SANDGLASS RUINS

明るい砂漠の遺跡を左から右へ進む協力ステージ。`assets/stage_1_6/concept_board_v2.png`
の丸い砂岩と青い空を基準に、ゲーム内では遠景を控えめにして足場と敵を読みやすくした。

## 経路

- 序盤は高さの異なる砂岩の足場を走り抜け、バネで高いコインを取れる寄り道もある。
- トゲとサボテンを飛び越え、木橋から高台に上がる。
- 3枚の崩れる石を連続で渡る。接地後0.45秒で崩れるので、止まらず次のジャンプへつなぐ。
- 550pxの谷はガーディアンの足場で協力して越える。
- 昇降する砂岩の足場で高台に上がり、点滅する3枚の足場をリズムよく渡る。
- 後半の砂岩門では、ガーディアンにだけ門の要求記号、ランナーにだけ2つの遠隔スイッチの記号が見える。ランナーが一致する場所を伝え、ガーディアンが撃つと8秒間だけ門が開く。門の直前にチェックポイントがある。
- 方向が変わるベルトと下りの連続ジャンプを抜け、最後の崩れる石を渡って門へ向かう。
- 難所の後に9箇所のチェックポイントを配置し、失敗後すぐ再挑戦できる。

## 敵

| 敵 | 動き |
| --- | --- |
| 石甲虫 | 地上を速く往復する。2発で倒れる。 |
| 歩くサボテン | 地上をゆっくり巡回する。 |
| 砂時計クラゲ | 空中を左右に漂い、上下にも揺れる。 |
| 砂ヒレ | 地面に沿って素早く往復し、ときどき砂から跳ねる。 |

敵の種類と位置は `src/levels/level_desert_data.gd`、動きは
`src/entities/enemies/desert_enemy.gd`、見た目は
`src/entities/enemies/desert_enemy_visual.gd` にある。敵は既存の `Enemy`
を継承し、ほかのステージと同じ射撃・接触・オンライン同期を使う。
