# Every Godot test and tool scene, and how it runs. tools/check-test-manifest.py
# (a verify.sh step) fails if a scene is missing here, or if one marked gated
# is not actually run by tools/verify.sh -- "a test nobody runs" is the thing
# this file exists to prevent.
#
#   gated      tools/verify.sh runs it; CI fails if it fails
#   shots      tools/verify.sh --shots (needs a display); CI runs it under xvfb
#   perf       tools/perf-gate.sh, against tools/perf_budgets.cfg
#   live       needs a running relay or several processes; run by hand with
#              the script named (see docs/release-acceptance.md)
#   capture    renders pictures for the store, the menu cards or review; not a test
#   tool       a build or asset tool, not a test
